THE SHORT ANSWER

Why there is no Pixabay plugin for Resolume.

Resolume's plugin format is FFGL. FFGL plugins are compiled GPU effects and generative sources, essentially shaders with parameters. That format has no sensible way to present a searchable stock library, download files, manage a cache or handle an API key. It is the wrong shape for the job, which is why nobody has shipped one.

Since version 7.8, though, Resolume exposes a REST API and a local webserver. That API can open a media file into any clip slot. So the bridge does not try to be a plugin at all. It runs beside Resolume as a small local app, handles the searching and downloading itself, and hands finished files to Resolume through the door Resolume already provides.

HOW IT WORKS

Search, send, trigger.

Four steps, about five minutes for the first run.

  1. 1

    Turn on the webserver

    In Resolume: Preferences, Webserver, switch it on. Default port 8080. This is what lets local tools talk to your composition.

  2. 2

    Run the bridge

    Run python3 resolume_bridge.py. The window opens at 127.0.0.1:5566 and shows a green badge with your Resolume version once connected.

  3. 3

    Search Pixabay

    Paste a free Pixabay key once. Then search. Results show duration, resolution and whether you already have the clip cached.

  4. 4

    Send to a slot

    Pick a layer, leave the slot on Auto to fill the next free one, and press Send. Tick "trigger after send" to fire it the moment it lands.

CODEC NOTE

H.264 in, DXV if you need it.

Pixabay serves H.264 MP4 files. Resolume plays them, but its native DXV codec scrubs and scratches far better under load. For casual triggering, send clips as they come. For a demanding show, run the cached files through Resolume Alley and convert to DXV first. Alley is free.

LICENSING

Know what you are projecting.

Clips come from Pixabay under the Pixabay Content License, which is permissive for most performance use. The bridge saves the source page and contributor name next to every cached file so you can always trace a clip back. Check the license yourself for commercial or broadcast work.

QUESTIONS & ANSWERS

Stock Bridge FAQ

Is there a Pixabay plugin for Resolume?

No. Resolume has no official Pixabay plugin and no third-party FFGL plugin provides one. FFGL is built for GPU effects and generative sources, so it cannot sensibly browse a stock library, download files or hold an API key. The Stock Bridge solves the same problem from outside Resolume, using the REST API that Arena and Avenue already expose.

How does the bridge actually load a clip?

It posts the cached file path as a file:// URI to /api/v1/composition/layers/{layer}/clips/{clip}/open. Resolume then treats that slot exactly as if you had dragged the file in yourself. If you tick trigger after send, the bridge also calls the matching connect endpoint.

Which Resolume versions are supported?

Arena and Avenue 7.8 or later, which is when Resolume added the REST API and webserver. Turn the webserver on under Preferences. Arena-only features like projection mapping are not required.

Does it cost anything?

No. The bridge is free with no account and no subscription. You bring your own free Pixabay API key.

Will Pixabay clips play smoothly in Resolume?

Pixabay serves H.264, which Resolume plays but does not scrub as cleanly as DXV. Fine for triggering. For heavy use, convert cached clips to DXV with Resolume Alley.

Where are the downloaded clips stored?

In your home folder under VideoMixer/cache/stock/media, with a small metadata file per clip recording the Pixabay page, contributor and license. ELYWARE Video Mixer uses the same cache, so anything you download is available in both apps.

Can it send to a specific slot instead of the next free one?

Yes. The slot dropdown lists every clip slot on the chosen layer. Auto simply picks the first empty one so you do not overwrite something you have already cued.
