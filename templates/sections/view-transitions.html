View transitions

Pages cross-fade instead of blinking.

kit.css turns on cross-document view transitions for every page that loads it. No JavaScript. Browsers without support just navigate normally.

This card has class="vt-hero". Put the same class on one element of the next page and it morphs between them. Use one per page.
